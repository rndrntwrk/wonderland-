# Approved original behavior integration

This is qualification of the existing cooker, bridge and native runtime. It is
not proof of account-owned admission, a rendered avatar, or the two-account
player journey. The original content, derived packs, decoded routine reports,
and runtime snapshots remain private. This directory contains only generic
contracts, hashes, counts and observations.

The source baseline is `4c6b3e8f5835b228723caea3c9f683c62f244f73`.

## Implemented adapters

- Resolver-wide ordered PIFF candidates apply to private/global/semiglobal
  targets. Indexed originals retain exact source identity and rebuild their
  indexes between accepted patches.
- Scoped original/rewrite OTF caches follow the pinned provider precedence.
  Old explicit inputs retain their identity and tuning-pack v1 encoding; scoped
  OTF origins use a backward-compatible v2 envelope.
- Bounded original OBJf zero tags and SLOT version thresholds are accepted and
  preserved according to the pinned readers.
- Optional source metadata normalization derives single-tile footprints,
  startup placement and exact-integral routing-slot values. Unsupported
  multipart/fractional metadata fails closed. No appearance is substituted.
- `tuning.dat` uses the existing bounded QFS decoder and source string/key
  semantics. Motive conversion requires every source key and float32 conversion.
- Missing action-zero TTAB rows remain in original/cooked resources but are not
  made actionable. Existing BHAV 0 is not silently dropped. Source TTA indices
  retain their identities.

## Observed results

The effective TemplatePerson, destination and retained racing banner resolve.
All effective TTAB action/check and OBJf roots have complete direct-call graphs.
This does not prove dynamic named-tree or object-creation dependencies.

The original installation identifies itself as TSO `1.1097.1.0`, which the pinned
startup supports directly. The retained 1239-to-NI conversion applies only to
`1.1239.1.0` and was not applied.

With source-derived new-VM globals and exact local GenericTSO query semantics,
fresh TemplatePerson spawning executes 164 instructions and the following
authority tick executes 35. The original destination menu returns Walk, Run,
Face and Point at unchanged TTA indices 2, 4, 6 and 7. The tightened isolated
runtime probe starts the selected Walk at tick 6, reaches the requested position
and reports successful route/action completion at tick 17. Original idle then
resumes. Authority and replica remain equal through tick 302, with no thread
faults or external effects. This uses an explicit unowned test principal.

All 935 runtime-consumed original semantic resources, including complete
behavior scopes, now pass the shipping cooker, sealed binding and loader in one
419,236-byte private pack. The manifest is 792,698 bytes and binding 47,191 bytes.
The source and cooked runtime tuning hashes agree. The established cooked
contract hashes ordered scope projections and reports a distinct pre-table
content descriptor. A separate tightened replay uses `PreparedRelease::load`
and `GameRuntime::from_cooked`, then proves the same original menu and successful
Walk, no faults/effects, and exact authority/replica equality through tick 302.
A receipt binds source inputs, effective identities, tuning.dat, manifest and
binding.

The loader uses an explicit hard 64 MiB metadata admission bound and unchanged
32 MiB conversion/final-content limits. Metadata remains charged to the caller's
aggregate allocation allowance. Shared global scope reuse requires a matching
bound donor and exact global cache/replacement equality; no provenance is
rewritten.

The private generic probe is
`tools/replay/native_original_content_qualification.rs`. Its required arguments
are a private cook spec, approved tuning.dat, and a private output directory.
Its reports include decoded proprietary operands and must not be published.

The selected PIFF order is recorded explicitly. The pinned provider uses
unspecified directory enumeration, so this is not called canonical source order.
Swapping the global and person-global same-target pairs preserves effective
content and tuning. Swapping the destination pair preserves tuning but changes
the ordered effective IFF, so that pair is not claimed to commute. The selected
sequence and exact effective identities remain pinned.

Focused tests already passed: cooker import 13, resolution 14, tuning-pack 3,
indexed IFF 21, OBJf 6, visual formats 14, tuning.dat 2, source metadata 3,
and bridge content import 13. The final focused bridge/cooked run passed 59
