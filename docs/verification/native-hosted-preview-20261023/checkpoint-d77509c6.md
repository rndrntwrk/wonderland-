# Native hosted supervisor and automatic original content

Qualified local source: `d77509c66021aa310978b3f7a1942ee46d2062e1`, tree
`c234cf25ecc24c21fac347c0592c226c19f37bc3`. Public source publication uses a
separate commit on PR #81, preserving its existing #80 dependency and documents.

The supervisor now has an explicit binding-backed hosted profile. Default
loopback behavior remains. Hosted account forwarding retains the real ingress
identity, private RPC stays behind the Container outbound boundary, and startup
recovery uses the existing durable coordinator/checkpoint protocol rather than a
local runner file. No public private-RPC endpoint is added.

After committed owned admission, the browser automatically obtains the pinned
original-content pack over authenticated same-origin POSTs. Every request checks
the account reservation and source placement; each resource is size/hash checked
on both sides. Browser bytes remain memory-only, with no-store responses and
stale-session rejection. This reuses the existing importer, FreeSO quaternion
sampling, retained pose history and CPU skinning. No replacement animation math,
synthetic actor, scripted Walk completion or public game-asset bundle is added.
