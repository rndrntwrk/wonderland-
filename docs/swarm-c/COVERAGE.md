# Swarm C coverage and acceptance ledger

The rows below describe the 17 scope items assigned to C: four under each of
W07–W10 plus SL.5. Their descriptions summarize the supplied plan; they are not
claimed to reproduce its original item titles verbatim.

An implemented algorithm is a usable code path with bounded inputs. Analytic
fixtures exercise selected source equations and failure cases. Differential
probes compare an actual source/runtime result. Engine execution proves an
artifact can run in the observed environment. Production acceptance also needs
the real providers, authorized content and target devices. These evidence
classes must not be substituted for one another.

The continuation adds concrete adapters in the existing [client integration
branch][client], with entry actions and validation commands in the
[client guide][client-guide]. Historical counts/commits below remain historical.
The completed C reference, source, native/WASM and engine GPU checks are
summarized below; the integrator records their exact source revision and artifacts
in [VERIFICATION.md](VERIFICATION.md).
The explicit source WCRC sunlight extension and client attachment are implemented;
its [independent source review](evidence/source-completion-review.md) is closed.
WCRC presence is a source component decision, independent of
Full2D/Hybrid2D/Full3D or Ultra. Client release/UI verification and authorized
content, live-service and physical-device acceptance retain their own scope.

## Reviewed WCRC source path

The [closed source review](evidence/source-completion-review.md) covers the
explicit wall/floor/roof/Ultra-object captures, four RGBA8 PCF stages, outdoor
SSAA, indoor bleed, and source identity/allocation boundaries. The supplied
512×512 noise follows `TextureUtils.Decimate`: integer RGB averaging over
nontransparent texels and maximum alpha. Its ten levels retain the source point
mip behavior; the recorded 32×32 GPU case selected mip 7 exactly.

The constant-run optimization proves that every possible source/noise-offset tap
has the same RGBA before reusing a result. It retains one cache entry per stage;
edge pixels execute the literal taps. All four quantized stages and stage two's

noise, a wall, upper floor and roof, plus an outdoor object in Ultra, under the
unchanged 250,000,000-work-unit default:

| --- | ---: | ---: | ---: |
| Normal | 41,690,764 | 20,321,680 | 12,197,504 |
| Ultra | 164,997,309 | 81,285,520 | 30,486,656 |

Both recorded actual WebGL2 PCF cases matched all **4,096 final RGBA bytes**
exactly, including raw red/green preservation in stage two. See the client
[PCF report][client-pcf-report], [source-noise mip report][client-pcf-noise-report]

## Conditions common to every row

The shared foundation enforces bounded frames/images/meshes, explicit content and
device generations, atomic admission and disposable caches. Its
[source notes](core-source-notes.md) document numeric policies and reference
rasterization choices.

The final C checks apply to the source snapshot identified by the retained
[provenance record](evidence/continuation-2026-10-06/toolchain-artifacts.json) and
verification ledger. A failed later check is not covered by an earlier pass. Licensed-content, service, browser, physical-device and performance
results should name the fixture/provider/device and retain their artifacts.
There is no aggregate “17/17 complete” claim in this ledger.
