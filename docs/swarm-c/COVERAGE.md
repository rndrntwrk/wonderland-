## Current evidence

[DELIVERY_STATUS.md](DELIVERY_STATUS.md) records the exact isolated WebGPU repair,
full-matrix source/run, built-client source/run, unchanged thresholds, archive
hashes and test scope. [VERIFICATION.md](VERIFICATION.md) and per-module source
notes retain earlier date/commit-specific source and library observations. The
[client guide](https://github.com/rndrntwrk/wonderland-/blob/feat/swarm-c-client-integration/docs/swarm-c/CLIENT_INTEGRATION.md)
records eight actual application scenarios and release identity.

An engine fixture pass is not full client delivery. An original-lot screenshot
with unavailable scenery is not complete original-content parity. Physical
mobile emulation, OS null audio and synthetic participants are not physical
device, audible-output or live multiplayer acceptance. Keep the original scope
and its remaining implementation visible until each row has the required proof.
