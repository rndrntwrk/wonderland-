# Authored asset-cooker fixture

`authored.iff` and `demo.json` are newly authored, redistributable content pipeline test inputs, dedicated to the public domain under CC0-1.0. They contain a small encoded BHAV, a BCON with constants 7 and 11, and a deliberately unknown ZZZZ chunk with preserved flags, label, zero byte and non-ASCII byte. No original game assets or installation files are included.

This fixture checks import, dependency declarations, deterministic packing, integrity verification and a simulation readiness load plan. It is not a playable simulation, a real chair, a catalog interaction, or evidence of a complete object provider.

Regenerate through `wonderland-asset-cooker demo <new-directory>`; the command creates these same authored inputs and executes the real public cook, verify and readiness plan. The BHAV is never executed by the cooker.
